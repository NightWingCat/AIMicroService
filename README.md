# 전생 동료 문고 — 우리가 함께 쓰는 전생 동화책

어릴 적 친구들과 돌려 쓰던 교환 소설처럼, 동료들이 한 장에 한 명씩 등장인물로 합류하며 **다섯 장면**을 이어 쓰는 판타지 그림책 웹 마이크로서비스입니다. 다섯 번째 장면이 끝나면 엔딩 크레딧이 올라가고, 한 권의 책으로 엮여 공유 링크로 나눌 수 있습니다.

## 흐름
1. **두 명으로 제1장 시작**: 부서명과 사우님 성함을 두 분 적고 첫 장면을 펼칩니다.
2. **매 장 새 사우 한 명 추가**: 제2~5장마다 한 명씩 초대합니다(총 6명). 진행 회차(1/5~5/5)와 등장인물 명단(부서 · 성함 · 판타지 배역)이 함께 보입니다.
   - `✉︎ 다음 사람에게 펜 넘기기`: 쓰던 원고를 링크로 넘기면, 받은 사람이 다음 장을 이어 씁니다.
3. **엔딩 · 크레딧 후 책으로**: 엔딩 크레딧이 올라간 뒤 표지 → 속표지(목차) → 등장인물 → 제1~5장 → 엔딩·크레딧 순서의 그림책 뷰어로 바뀝니다.

## 주요 기능
- **부서 성격 반영**: 부서명에서 결을 읽어(개발 → 구조·탐구·기록·집중, 디자인 → 색채·형태·비율·미감 등 16가지 + 기본형) 판타지 배역·소품·장면 속 행동으로 바꿉니다.
- **1페이지 1장면 그림책**: 장면마다 SVG 동화풍 일러스트(부서별 의상 색·소품·모자, 이름별 머리 모양·피부톤), 만화 컷 테두리, 내레이션 박스, 새 인물의 말풍선이 들어갑니다. 장이 넘어갈수록 하늘이 밤에서 새벽으로 바뀝니다.
- **집필**: OpenAI API 키가 있으면 AI가 앞 장의 원고를 이어받아 씁니다. 키가 없으면 내장 이야기 엔진(4개 세계 × 5막 구성, 한국어 조사 자동 처리)이 씁니다.
- **읽어주기**: OpenAI TTS(`/v1/audio/speech`, `gpt-4o-mini-tts`)로 현재 페이지를 읽습니다.
  - 재생 / 일시정지 / 정지, 음성 11종(coral, alloy, ash, ballad, echo, fable, nova, onyx, sage, shimmer, verse), 속도 0.75~1.5×
  - 연속 읽기(다음 페이지로 넘기며 이어 듣기), 처음부터 끝까지 듣기
  - 키가 없거나 호출에 실패하면 브라우저 `speechSynthesis`로 읽고, 그것도 없으면 안내만 보여 줍니다.
- **공유**: 책 전체를 압축해 URL 해시(`#b=…`)에 담습니다. 서버 없이 링크만으로 완성된 책 뷰어가 바로 열립니다. 그 밖에 줄거리 전체 복사, PDF로 간직하기(인쇄), 다른 앱으로 공유를 지원합니다.
- 쓰던 원고는 이 브라우저에 자동 저장됩니다.

## 규칙
연애·궁합 요소 없음 · 개인정보를 묻거나 만들지 않음(연락처·이메일처럼 보이는 입력은 막음) · 업무 능력이나 성향을 비하하지 않음 · 샘플 채우기 버튼 없음

## 실행
의존성 없는 단일 `index.html`입니다. 브라우저로 열거나 정적 호스팅(Vercel)에 올리면 됩니다. OpenAI 키는 브라우저에서 `api.openai.com`으로만 전송됩니다.
