# 전생 체험관

[팀명]과 [성명]을 두 명 이상 적고 **전생 체험하기**를 누르면, 빛이 소용돌이로 빨려 들어가는 연출과 함께 전생의 한 장면이 나타나 우리가 어떤 사이로 만났는지 풀어 주는 웹 마이크로서비스입니다.

## 결과 구성
- **스냅샷**: 등장인물이 그려진 꿈속 같은 장면 일러스트와 한 줄 묘사
- **시대 · 관계 꼬리표 · 제목** (예: `조선 · 한양 운종가 · 250년 전` · `인절미 앙숙 → 30년 동업자`)
- **요약**: 먼저 두세 문장으로
- **각자의 전생**: 팀의 결이 반영된 전생 직업과, 그 인연에서 한 일 두 문장
- **인연의 전말**: 자세한 이야기 (접어 두고 펼쳐 보기)
- **현생에서**: 지금 우리 사이에 남은 흔적 한 줄
- 다른 전생도 체험하기 · 결과 복사 · 링크 공유 (링크를 열면 같은 장면이 그대로 열림)

## 동작
- 분위기 선택: 운명에 맡기기 / 진중하게 / 유쾌하게
- **내장 이야기**: 9개 전생 시나리오(진중 5 · 유쾌 4), 팀 성격 16가지 + 기본형, 한국어 조사 자동 처리, 2~8명 지원
- **OpenAI 키(선택)**: 입력하면 AI가 같은 구성으로 새 이야기를 지어 줍니다. 키는 브라우저에서 api.openai.com으로만 전송됩니다.

## 규칙
연애·궁합 요소 없음 · 개인정보를 묻거나 만들지 않음 · 업무 능력·성향 비하 없음
