# 전생 동료 극장

팀명과 이름만 넣으면, 입력한 사람들이 한 편의 **전생 단편 시나리오** 속 등장인물로 얽힌 이야기를 엮어 주는 웹 마이크로서비스입니다. 슬랙 연동 없이 바로 씁니다.

## 출력
- **시나리오 제목**
- **스냅샷**: 장면 묘사 한 줄
- **등장인물 배역**: `(팀명 / 이름)`과 전생 역할 한 줄
- **인연 서사**: 어떤 계기로 만나 얽혔는지 3~6문장
- **에필로그**: 지금의 팀으로 다시 만났다는 한 줄

## 생성 방식
- **OpenAI API 키가 있으면**: 브라우저에서 `api.openai.com`으로 바로 호출합니다(기본 모델 `gpt-4o-mini`, 변경 가능). 키는 다른 서버로 보내지 않고, "이 브라우저에만 저장"을 켰을 때만 localStorage에 저장합니다.
- **키가 없거나 호출이 실패하면**: 내장 생성기가 즉시 만듭니다. 팀명에서 성격을 유추해(개발 → 구조·원리·정밀함, 디자인 → 색채·비율·형태 등 16가지 결 + 기본형) 9개 전생 세계관의 배역·도구·사건에 녹여 냅니다. 한국어 조사(은/는, 이/가, 과/와, 으로/로)를 자동 처리합니다.

## 규칙
1. 연애·궁합·커플 매칭 요소 없음
2. 개인정보·민감정보를 묻거나 만들지 않음 (연락처·이메일처럼 보이는 입력은 막음)
3. 업무 능력·성과·성향을 비하하거나 조롱하지 않음

## 공유
- 다른 시나리오로 다시 엮기
- 전체 텍스트 복사 / 공유용 요약 복사 / 다른 앱으로 공유(지원 기기)
- 결과 링크 복사: 결과 전체가 URL 해시(`#r=...`)에 담겨 서버 없이도 같은 카드를 엽니다
- 카드 이미지(PNG) 저장

## 실행
의존성 없는 단일 파일입니다. `index.html`을 브라우저로 열거나 정적 호스팅(Vercel 등)에 올리면 됩니다.
