# 전생 체험관

[팀명]과 [성명]을 두 명 이상 적고 **전생 체험하기**를 누르면, 빛이 소용돌이로 빨려 들어간 뒤 우리의 전생이 **고전 명화 한 폭**으로 나타나는 웹 마이크로서비스입니다.

## 결과 (한 장짜리 포트폴리오)
- 금빛 액자 속 **하찮은 그림** (삐뚤빼뚤한 선, 감자 몸통, 멍한 표정, 손글씨 이름표, 장면 소품) + 제목·시대 명판
- 장면마다 다른 **역동적 구도** 58가지: 칼끝 대치, 추격, 줄다리기, 업고 가기, 어깨 위 올라타기, 폭발에 날아가기, 정면충돌, 노 젓기, 활 겨누기 등 + 속도선·먼지·땀·느낌표 효과, 나머지 인물은 뒤쪽에서 응원
- **플레이버 텍스트** 한 줄 — 예: “너를 용서하지 않겠다!”
- 장면 설명 1~2문장 — 예: 과거 둘은 서로 적국의 용맹한 전사로 만나 전장에서 칼끝을 마주 겨누며 끝까지 싸워 나갔다.
- 관계 꼬리표 (예: 적국의 전사 → 평생의 맞수)
- 등장인물: 성명 · 팀 · 전생 배역 · 팀의 결 (예: 북국의 전사 · 묵묵함)
- 이미지 저장(1080px PNG) · 링크 공유 · 텍스트 복사 · 다른 전생 체험하기

## 동작
- 진중한/유쾌한 이야기는 매번 랜덤, 유쾌한 쪽이 약 70%
- **조합형 이야기**: 장소 19 × 사건 33 × 결말 18 × 물건 24 × 대사·배역을 맞물려 매번 새 시나리오를 짓습니다 (사건마다 어울리는 구도·물건 종류, 물가·높은 곳 같은 장소 조건을 맞춰 말이 되는 조합만 사용). 손으로 쓴 명작선 32편도 열에 셋 정도 섞여 나옵니다.
- 스냅샷 구도 58종 (사건마다 두 가지 연출) · 배경 34종 (장소마다 두 가지 시간·날씨: 노을, 비, 눈, 오로라, 밤, 새벽, 단풍, 모래폭풍, 벚꽃, 안개, 푸른 수정 동굴 등)
- 팀 성격 16가지 + 기본형을 배역 옆 '결'로 반영, 2~8명 지원
- OpenAI 키(선택)를 넣으면 AI가 같은 형식으로 새로 지어 줍니다. 키는 브라우저에서 api.openai.com으로만 전송됩니다.
